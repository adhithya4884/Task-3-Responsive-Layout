Main Content Area

This is the main content section. On larger screens, it appears next to the sidebar, creating a grid layout. However, on smaller screens (like mobile devices), this section will stack below the sidebar for better readability and user experience.

This responsive behavior is achieved using CSS media queries. We define the mobile layout first (stacked, single column) and then apply different styles for screens that are "medium" or wider.
